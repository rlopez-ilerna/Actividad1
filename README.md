# Ilerna - Despliegue de aplicaciones web

## Descripción

Este proyecto pertenece a la asignatura de **Despliegue de Aplicaciones Web** del ciclo de Desarrollo de Aplicaciones Web (DAW).

El objetivo del proyecto es aprender a utilizar **Git y GitHub** para gestionar proyectos de software y trabajar de forma colaborativa.

## Contenido del proyecto

En este repositorio se realizarán diferentes actividades relacionadas con:

- Control de versiones con Git.
- Uso de ramas.
- Creación de commits.
- Uso de GitHub.
- Gestión de Issues.
- Uso de Releases.
- Documentación mediante Markdown.
- Trabajo colaborativo.

## Objetivo

El objetivo principal es aprender a gestionar y documentar un proyecto utilizando herramientas de control de versiones como **Git y GitHub**.

## Tecnologías utilizadas

- Git
- GitHub
- Markdown
- Visual Studio Code
